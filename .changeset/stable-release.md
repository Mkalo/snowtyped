First stable release. The public API, compatibility range, and data representations described in the [release contract](https://github.com/Mkalo/snowtyped/blob/main/docs/release-contract.md) are now covered by semantic versioning: incompatible changes to stable APIs need a major release. The AST layer and the `snowtyped/ddl` entry point stay experimental and may change in a minor release. Upgrading from `0.1.0-alpha.2` needs no code changes.
