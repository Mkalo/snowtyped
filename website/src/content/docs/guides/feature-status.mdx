Snowtyped is versioned as an alpha prerelease. Breaking changes can land in any release until a
stable version is published; each one is recorded in the [changelog](/project/changelog/).

## Supported runtimes

| Runtime         | Supported versions          |
| --------------- | --------------------------- |
| Node.js         | 22.18+ and 24.11+           |
| `snowflake-sdk` | ^3.4.0 (optional peer)      |
| Module formats  | ESM and CommonJS            |
| Declarations    | `.d.mts` and `.d.cts`       |

CI runs the library checks on Linux and Windows with Node 22 and 24.

## First-class APIs

- Declared schemas for text, integer, decimal, float, boolean, date, time, timestamp, binary, and
  VARIANT columns, with precision, scale, and length constraints. See
  [schema declarations](/guides/schemas/).
- SELECT with projections, joins, aliases, grouping, aggregates, ordering, DISTINCT, pagination,
  derived tables, CTEs, recursive CTEs, and set operations. See [queries](/guides/queries/).
- Typed expression helpers: arithmetic, CASE, COALESCE, casts, text and date functions, and ranking
  and offset windows. See [queries](/guides/queries/) and [Snowflake syntax](/guides/snowflake-syntax/).
- Window functions with ROWS and RANGE frames, QUALIFY, FLATTEN, ASOF JOIN, PIVOT, UNPIVOT,
  MATCH_RECOGNIZE, and time travel. See [Snowflake syntax](/guides/snowflake-syntax/).
- INSERT, UPDATE, DELETE, and MERGE, including INSERT … SELECT, UPDATE … FROM, DELETE … USING,
  conditional MERGE branches, server defaults, identity, and virtual columns. See
  [mutations](/guides/mutations/).
- Parameterized raw SQL. See [raw SQL](/guides/raw-sql/).
- Execution, streaming, cancellation, transactions, and pooling. See
  [execution](/guides/execution/). The production scenarios that gate a stable release
  (cancellation, pool waits and pressure, streaming, transactions, failures, no implicit
  retries, and sustained use) have unit and live coverage; see
  [production use](/guides/production/) for operational limits.
- Introspection and declaration generation. See [introspection](/guides/introspection/).

## Not first-class in this alpha

Complex nested relation projections, migrations, DDL builders, and ORM relation loading are not
modeled. A public third-party AST registration protocol is not implemented.

[Raw SQL](/guides/raw-sql/) can execute Snowflake syntax beyond the modeled builder surface.
