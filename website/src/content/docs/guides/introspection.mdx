`introspect(db, { database, schema })` reads the columns visible to the connection's role through
`INFORMATION_SCHEMA`. `generateSchema(tables)` returns TypeScript source that declares each table
with its exact physical names, exported as `table0`, `table1`, and so on in a stable order. Generated
declarations carry NUMBER precision and scale, VARCHAR length, and TIME and TIMESTAMP precision when
they differ from Snowflake's defaults. `INFORMATION_SCHEMA` does not report BINARY length. Column
defaults, identity settings, and virtual column expressions become `.serverDefault()`, `.identity()`,
and `.virtual()` modifiers. Structured ARRAY, OBJECT, and MAP columns become `structured()`
declarations, with exact field names read from `SHOW COLUMNS`.

<Snippet code={introspect} />

Review generated declarations, rename the exports, and commit them to your project. Unsupported data
types fail explicitly; Snowtyped does not invent codecs or schemas for them. Results are limited to
what the connection's role can access.
