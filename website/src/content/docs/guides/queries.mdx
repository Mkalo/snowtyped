`select(table)` selects every declared column. `select(table, projection)` or `.select(projection)`
selects specific columns and expressions. Projection keys become the exact output aliases.

<Snippet code={firstQuery} />

Builders are immutable. Each call returns a new query, and calling a clause such as `.where()`
again replaces that clause on the new query.

## Expressions

| Category    | Helpers                                                       |
| ----------- | ------------------------------------------------------------- |
| Comparison  | `eq`, `ne`, `gt`, `gte`, `lt`, `lte`                          |
| Logic       | `and`, `or`, `not`                                            |
| Nullability | `isNull`, `isNotNull`                                         |
| Membership  | `inArray`                                                     |
| Text        | `like`, `ilike`, `lower`, `upper`                             |
| Aggregates  | `count`, `sum`, `min`, `max`                                  |
| Ordering    | `asc`, `desc`, with optional `FIRST`/`LAST` null ordering     |

Literal values become bind parameters. An empty `inArray` list compiles to a constant false, or
true for a negated membership test.

## Joins

Inner, left, right, full, and cross joins are supported. Project joined columns after joining so
they are in scope. Outer joins make the columns of the optional side nullable in the result type.

<Snippet code={joins} />

Use `alias(table, 'name')` for repeated table names. Table and alias scopes are checked statically
and at runtime; dynamic identities that share a static name are distinguished at runtime.

<Snippet code={aliases} />

## Grouping and pagination

Use `.groupBy(...)`, `.having(predicate)`, `.orderBy(...)`, `.distinct()`, `.limit(n)`, and
`.offset(n)`.

<Snippet code={grouping} />

Counts decode as `bigint`. Sums decode as exact decimal strings and are nullable, because a sum
over an empty group is NULL. Grouping legality beyond the supported expression and scope checks is
enforced by Snowflake. With `.distinct()`, order expressions must be projected.

## Derived tables and CTEs

`.as('name')` turns a query into a derived table, and `.asCte('name')` makes it a CTE source. The
result's `.columns` keep their inferred output types and outer-join nullability. Selecting from or
joining a CTE includes its definition automatically.
