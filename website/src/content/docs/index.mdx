<CardGrid>
  <Card title="Declared schemas" icon="document">

    interfaces or decoders for structured queries.
  </Card>
  <Card title="Snowflake syntax" icon="seti:db">

  </Card>
  <Card title="Exact values" icon="approve-check">
    Integers decode as `bigint`, decimals as exact text, and timestamps keep nanoseconds.
  </Card>
  <Card title="Raw SQL when needed" icon="pencil">
    Parameterized tagged templates cover syntax beyond the builder, with explicit result assertions.
  </Card>
