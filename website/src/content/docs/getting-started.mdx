## Requirements

- Node.js 22.18+ or 24.11+.
- [`snowflake-sdk`](https://www.npmjs.com/package/snowflake-sdk) 3.4 or later. It is an optional
  peer dependency: you need it to connect to Snowflake, but pure query compilation does not load it.
- Zod is a runtime dependency and is installed with Snowtyped.

## Install

```sh
pnpm add snowtyped snowflake-sdk
```

Stable releases are published under the `latest` npm dist-tag. See
[feature status](/guides/feature-status/) for what is covered and [releases](/project/releases/)
for the release channels.

Snowtyped ships ESM and CommonJS builds with matching declarations. The main entry point,
`snowtyped`, contains schema declarations, the query builder, and the `sql` tag. Execution helpers
live in `snowtyped/snowflake`.
